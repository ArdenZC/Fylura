# Fylura brand assets

The current README banners, icon artwork, Windows `.ico` files, macOS `.icns` files, PNGs, installer illustrations, and DMG background are temporary engineering assets. They carry the pre-design placeholder artwork and are not the approved Fylura logo. The final logo remains in design.

The generated PNG, ICO, and ICNS sizes are produced by `npm run assets:brand` from the local `temporary-brand-source.html` token fixture. That fixture exists only to make the generator reproducible; it is not a logo source. The generator also produces the Windows installer bitmaps and DMG background.
