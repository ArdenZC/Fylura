# Removing Fylura data on macOS

Dragging `Fylura.app` to Finder Trash is an ordinary app removal. It leaves the user's Fylura data in place so reinstalling the app can resume with the same settings, database, History, Journal, Restore records, API credentials, and Safe Trash.

To remove Fylura's own data as well, run `Fylura.app/Contents/Resources/Uninstall Fylura Data.command` before removing the app. The command file is intended to present an interactive confirmation and stop if Fylura is running; its graphical interaction has not been verified. The packaged application's `--fylura-uninstall-clean-user-data` path removes only the current user's `com.startlan.fylura` Application Support and cache directories, matching Preferences plist, matching Fylura LaunchAgent, and AI Keychain entries under the exact `com.startlan.fylura` and `com.startlan.fylura.ai-profile` services. Profile credentials are enumerated from Keychain attributes, so cleanup does not depend on a readable database or its current Profile list. It verifies that the targeted credentials and files are gone; an inspection or deletion error is reported as incomplete.

The cleanup preserves `safe-trash`, `.fylura-trash`, and legacy `.zen-canvas-trash` roots, including their files. Deleting the database also deletes History, Journal, and Restore metadata, so files left in Safe Trash may no longer have Fylura restore records. It does not clean old Zen Canvas application data or credentials, user documents, Finder Trash, or Safe Trash roots.
