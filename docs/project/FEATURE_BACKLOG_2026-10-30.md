## 1. 统计与判定边界

- 本次统计按**独立用户能力或交付门槛**计，不以 PR 数量计算“完成率”。
- “已合并”=有合并代码/当前主干路径证据；不代表原生 Windows/macOS 验收通过。
- “部分实现”=有可信基础，但完整目标/实际跨平台闭环不足。
- “研究/默认关闭”=原型、shadow 或冻结实验，不作为默认生产用户能力。
- “未实施/无完整证据”是**未找到可信的完整生产实现**，不排除某些分散 API 或旧行为存在；后续应以调用链和 GUI 复核。
- “明确延后/研究暂停”不是失败，不能自动转成排期。
- 优先级定义：P0 用户数据/核心闭环或验收阻断；P1 日常高价值；P2 差异化提升；P3 长期候选。
