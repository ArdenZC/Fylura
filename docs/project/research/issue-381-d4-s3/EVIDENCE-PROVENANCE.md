# Evidence provenance

## D4-S2 raw log correction

The frozen D4-S2 `SHA256SUMS` and `INPUTS.json` referenced `schema37-physical-harness-run.log` with SHA-256 `317ccfe4bd885746d8ded808dcdc96c0ef117c57bc12631a7c2808fd84067f06`. At frozen D4-S2 HEAD, that file was not in the commit tree. The original log remained present in the D4-S2 worktree and its bytes matched the referenced SHA-256. It was copied byte-for-byte into `evidence/archive/d4-s2-schema37-physical-harness-run.log`; that archive has the same SHA-256.

No D4-S2 output was reconstructed from the JSON, shell history, or a rerun. This branch now makes the actual original log available for review, while retaining the distinction that it was absent from the D4-S2 commit itself.

## D4-S3 run evidence

`manifest-authority-run.log` and `manifest-authority-results.json` were generated by the committed D4-S3 runner command from `VALIDATION-CONTRACT.md`. They contain synthetic Schema 37 test data only. The structured result records runtime SQLite version/source id and the input SQL/DDL digests.
